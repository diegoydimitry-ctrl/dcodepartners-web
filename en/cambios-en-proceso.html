Changes in Progress

What we are building now and what is operational.

In progress 4 fronts

D-Code Finance, stronger

We are extending the financial system: more screens, document reading that files each invoice where it belongs, and an assistant that answers with the company’s own numbers. The goal is that nothing already written on a piece of paper ever has to be typed again.

Evolving

The layer everything runs on

Underneath Finance we are building the common layer — permissions, per-company isolation, a record of everything that gets touched and a single API — so that any new system is born with it instead of rebuilding it every time.

Under construction

VERI*FACTU: submission to the AEAT

Every invoice record is already produced and chained from the moment of issue. The next step is submission to the AEAT, and this board changes when there is proof of each step.

Ready

Bank reconciliation in Finance

The bank statement, matched against invoices and expenses, so that what has been collected and paid adds up without checking it by hand. It is not in the system yet: it is the next piece of D-Code Finance.
